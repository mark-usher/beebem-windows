Acorn FileStore E01 and E01S

The Acorn FileStore is a stand-alone Econet file server. BeebEm emulates the FileStore E01 (separate OS and file server ROMs) and the E01S (one combined ROM), including the CPU (a 65C102, emulated as a 65C12), system VIA, 146818 real-time clock and CMOS RAM, WD2793 floppy disc controller, SCSI hard drives and the Econet interface. Select the model from Hardware → BBC Model.

The FileStore has no display or keyboard, so the emulator window shows its front panel: the FileStore unit with its MODE LED and, below it, a hard drive unit for each SCSI drive attached (see below). Econet is always enabled in FileStore mode; set the FileStore's station number in Econet.cfg as for any other station (see Econet Support).

Discs

The FileStore uses ADFS format floppy discs in drives 4 and 5 (BeebEm drives 0 and 1), and SCSI hard drives 0 to 3, which use the scsi0.dat to scsi3.dat image files in the hard drive folder (see Hard Disks). Each SCSI drive is selected by its target ID. Floppy discs can only be loaded, created or ejected while the drive door is open.

Hard drive units

Hardware → SCSI Hard Drive On/Off turns all the hard drives on or off. Then, for each of drives 0 to 3, Hardware → FileStore Hard Drive Units chooses the unit attached:

  • None: no drive is attached.
  • Auto (the default): the drive is attached if its image file exists, and labelled from the image size: E20 up to 25 MB, E40 S up to 45 MB, otherwise E60 S.
  • E20, E40 S or E60 S: the drive is attached and shown with that label.
  • Custom: the drive is attached and shown with your own label of up to 4 characters after "FILESTORE". A custom label is set in the preferences file (see below), and then appears in the menu.

Each attached drive is shown as a unit below the FileStore, and the window is sized to fit. Changing a drive restarts the FileStore, after letting it write its buffers to disc.

The settings are saved in the preferences file as FileStoreDrive0 to FileStoreDrive3, each set to None, Auto, E20, E40S, E60S, or a custom label of up to 4 letters, digits, spaces, '-', '.' or '/', for example: 

FileStoreDrive0=E40S
FileStoreDrive1=E60S
FileStoreDrive2=CUST
FileStoreDrive3=None

Front panel controls

File → FileStore Door Open opens or closes the drive door flap. Opening the door puts the FileStore into maintenance mode, which writes its buffers to disc.

When you reset or exit BeebEm, or change to another model, BeebEm first opens the door and waits two seconds so that the FileStore can flush its buffers. The FileStore keeps running when the BeebEm window is inactive.

CMOS RAM

The E01 and E01S each have their own CMOS RAM, saved in the preferences file as CMOSRamE01 and CMOSRamE01S. The debugger command state c shows the clock registers and CMOS RAM. Saved state files are not supported for the FileStore.

The FileStore's station number is the one in its CMOS RAM (254 by default). The -EcoStn command line option overrides it for that session only: the FileStore sees the new number in its CMOS RAM, but the original number is kept in the preferences file. Without AUTOCONFIGURE in Econet.cfg, if there is no entry for the FileStore's station on this PC, one is added for the session (port 10000 + 256 × network + station); nothing is written to Econet.cfg.

Clock

The FileStore's clock normally follows the PC clock. It can be set, for example with a clock setting utility; to keep that setting over a reset and the next time BeebEm starts, tick Hardware → RTC Clock Offset (see the Real-Time Clock section).

The 146818's update cycle (once a second), periodic interrupt (at the rate the FileStore sets) and alarm are emulated, as the FileStore uses them for its timing.
